# Agung Ilham — Portfolio

Website portofolio pribadi sederhana menggunakan HTML dan CSS.

## Struktur folder

- `index.html` — halaman utama
- `style.css` — seluruh kode CSS
- `assets/profile.jpeg` — foto profil

## Menjalankan secara lokal

Buka `index.html` di browser.

## Upload ke GitHub Pages

1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini (bukan file ZIP-nya).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses deploy selesai. Website akan tersedia melalui alamat GitHub Pages repository tersebut.

## Kustomisasi

- Ganti teks perkenalan, keahlian, dan proyek di `index.html`.
- Ganti `assets/profile.jpeg` dengan foto sendiri (gunakan nama file yang sama), atau ubah alamat `src` pada tag gambar.
- Ganti `emailkamu@example.com` pada bagian kontak dengan email aktif.
